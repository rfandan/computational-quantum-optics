# Computational Quantum Optics: From Fundamentals to Frontiers

An open-source, hands-on computational curriculum covering quantum mechanics, quantum optics, and open quantum systems through Python and Google Colab notebooks.

---

## Curriculum Overview

| Module | Title | Notebook Count | Key Topics |
| :--- | :--- | :---: | :--- |
| **Module 0** | [QM Fundamentals](./module_0_qm_fundamentals/) | 5 | Wavefunctions, Qubits, Bloch Sphere, Commutators, QHO, Time Evolution |
| **Module 1** | [States of Light](./module_1_states_of_light/) | 7 | Fock, Coherent, Squeezed, Thermal States, Mandel $Q$, $g^{(2)}(0)$ |
| **Module 2** | [Phase Space & Quasiprobabilities](./module_2_phase_space_quasiprobabilities/) | 6 | Wigner, Husimi $Q$, Glauber-Sudarshan $P$, Cat States, Tomography |
| **Module 3** | [Light-Matter Interaction & Cavity QED](./module_3_light_matter_cavity_qed/) | 7 | Rabi Oscillations, Jaynes-Cummings, Dressed States, Mollow Triplet, EIT |
| **Module 4** | [Open Quantum Systems & Dissipation](./module_4_open_systems_dissipation/) | 7 | Lindblad Master Equation, Monte Carlo Trajectories, Input-Output, Micromaser |
| **Module 5** | [Multi-Mode & Quantum Information](./module_5_multimode_quantum_information/) | 7 | Beam Splitters, HOM Effect, TMSV / EPR, CV Teleportation, Boson Sampling |
| **Module 6** | [Advanced Frontiers](./module_6_advanced_frontiers/) | 6 | Optomechanics, Exceptional Points, Circuit QED, GKP / Cat Codes, GRAPE |

## Getting Started

### Local Setup
Clone this repository and install dependencies:
```bash
git clone https://github.com/<your-username>/computational-quantum-optics.git
cd computational-quantum-optics
pip install -r requirements.txt
```

### Google Colab
Each notebook includes an **Open in Colab** badge at the top so you can run the code with zero local setup.
