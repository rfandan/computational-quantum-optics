# Module 3: Light-Matter Interaction & Cavity QED

This module covers semiclassical and fully quantum interactions between atoms and electromagnetic fields, the Jaynes-Cummings model, dressed states, Mollow resonance fluorescence, electromagnetically induced transparency (EIT), Purcell microcavity enhancement, ultrastrong coupling, and Dicke collective superradiance.
