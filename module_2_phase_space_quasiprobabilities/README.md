# Module 2: Phase Space & Quasiprobability Distributions

This module explores phase-space quantum mechanics, quasiprobability distributions ($W$, $Q$, $P$, Cahill-Glauber $s$-parameterized family), quantum interference, sub-Planck action structures, non-classicality witnesses, and optical homodyne tomography.
